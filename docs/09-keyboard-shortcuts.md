# Keyboard shortcuts

## Goal

Use the built-in shortcuts without hunting through menus.

## Prerequisites

- Focus in the main app (not typing in a random OS field)

## Where to see them in the UI

**Settings → General → Keyboard Shortcuts** opens a modal: label on the left, keys on the right.

![Shortcuts modal placeholder](https://placehold.co/1200x800/ccc/f5f5f5/png?text=Keyboard+shortcuts+modal)

**Status: implemented** (list is **read-only** — custom rebinding is **Status: planned** / not in product yet)

## Built-in map

| Action | Keys |
|--------|------|
| Refresh current folder | `F5` or `Ctrl+R` |
| Go back | `Backspace` |
| Upload | `Ctrl+U` |
| Delete selected | `Delete` |
| Close modal / clear selection | `Escape` |

> **Note:** Exact labels follow the current language (EN / ID).

## Tips

- Shortcuts that act on selection need a selected row first.  
- When a modal has focus, Enter/Escape usually confirm/cancel that modal.
