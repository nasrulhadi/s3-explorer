# Settings

## Goal

Tune theme, language, toolbar, security, data backup, and updates.

## Prerequisites

- App unlocked

## Open Settings

Sidebar footer **gear** icon → Settings page.

![Settings page placeholder](https://placehold.co/1200x800/ccc/f5f5f5/png?text=Settings+page)

## General

| Control | What it does |
|---------|----------------|
| Restore last session | Reopen last bucket/folder on startup |
| Keyboard Shortcuts | Opens the shortcuts modal (read-only list) |

**Status: implemented**

## Appearance

| Control | What it does |
|---------|----------------|
| Theme | System / Light / Dark |
| Language | English / Indonesian |
| Accent color | Blue, green, yellow, brown, stone |

**Status: implemented**

## Security

Master password enable / change / disable, idle lock, related warnings.

See [Security and privacy](./07-security-and-privacy.md).
